# Security

For a suspected security vulnerability, email brett.c.schneider@gmail.com with the affected version, impact, and a minimal reproduction. Please avoid posting exploit details publicly before the issue has been assessed.

For navigation bugs or browser compatibility issues, use the public bug form. This library protects against accidental navigation; it does not provide authorization or persist form data.

Security fixes target the latest published version. Older versions do not have a separate backport policy.
